************ permanent live ************
If you want your backend server to be permanently active so that students can pay their fees at any time of the day without you keeping a terminal open or running commands on your laptop, you cannot keep hosting it on your local machine (localhost).

When you shut down your computer or close your terminal, your local server dies, and the fee button breaks.

To run the command only once and keep the backend alive forever, you need to deploy your backend to a free cloud hosting platform. Two of the absolute best and easiest platforms for Node.js backends are Render and Railway.
-------------------------------------
Here is how to set it up completely in a few minutes so it runs forever on the cloud.
-------------------------------------
Step 1: Update your HTML Frontend Fetch URL
Since your backend will live on the internet instead of your computer, you need to change your frontend HTML fetch URLs to point to your new cloud server instead of localhost.

Open your index.html (or wherever your payment script is) and find the two lines we edited earlier. Change them to look like this:

JavaScript
// Change localhost to your future cloud URL (you will get this link from Render/Railway)
fetch('https://your-pinnacle-backend.onrender.com/api/create-order', {
JavaScript
// Do the same for the verification endpoint
fetch('https://your-pinnacle-backend.onrender.com/api/verify-payment', {
Step 2: Push your Project to GitHub
Cloud hosting platforms pull your code directly from a GitHub repository to run it.
---------------------------------------
Create a new repository on your GitHub account named pinnacle-backend.
---------------------------------------
Open your terminal in your project folder and run these commands to push your code:

Bash
git init
git add .
git commit -m "Deploying payment backend"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/pinnacle-backend.git
git push -u origin main
(Note: Your .gitignore file is already perfectly configured, so your secret API keys in the .env file will not be leaked to GitHub).
-------------------------------------
Step 3: Deploy to Render (Completely Free)
Render will take your code from GitHub and host it in the cloud. It runs your start script automatically and keeps it online.
---------------------------------------
Go to Render.com and sign up using your GitHub account.

Click the New + button and select Web Service.

Connect your pinnacle-backend repository.

Set the following configurations on the screen:

Name: pinnacle-backend

Runtime: Node

Build Command: npm install

Start Command: npm start (This tells Render to run your server via node server.js once)

Instance Type: Free
